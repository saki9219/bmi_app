# ⚖️ BMI記録アプリ「My BMI」

身長と体重を入力するとBMI（Body Mass Index）を自動計算し、判定結果や健康アドバイスを表示するWebアプリです。

計算結果の履歴を保存できるほか、BMIに応じたおすすめ書籍も紹介し、健康管理のきっかけとなるアプリを目指して制作しました。

## 📌 主な機能

- BMIの自動計算
- BMI判定（低体重・普通体重・肥満）
- 判定結果に応じた健康アドバイス表示
- おすすめ書籍の表示
- 計算履歴の保存・削除
- LocalStorageによるデータ保存
- レスポンシブ対応

---

## 💡 工夫した点

### 判定結果を分かりやすく表示

BMI値だけでなく、判定結果や健康アドバイスを表示することで、利用者が結果を理解しやすい画面構成を意識しました。

### LocalStorageによる履歴保存

計算結果をLocalStorageへ保存し、ブラウザを再読み込みしても履歴を確認できるようにしました。

### BMIに応じたおすすめ書籍の表示

BMI判定に応じて表示する書籍を切り替え、健康管理や生活改善の参考になる情報を提供できるよう工夫しました。

### モバイルファーストで設計

スマートフォンでの利用を想定し、入力フォームやボタンサイズ、カードレイアウトなど操作しやすいUIを目指しました。

---

## 📚 苦労した点・学んだこと

BMIの判定結果に応じて表示内容を切り替える処理や、履歴データをLocalStorageへ保存・削除する処理の実装に苦労しました。

また、条件分岐を利用して表示内容を切り替える方法や、JavaScriptで配列データを管理する方法について理解を深めることができました。

UI面では、入力・結果・履歴・書籍紹介をカード形式で整理し、情報を見やすく配置するレイアウト設計を意識しました。
